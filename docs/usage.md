# Using Putter (early days edition)

There isn't a real feature to use yet — this doc exists so it grows alongside the app instead of getting written all at once at the end, by which point nobody remembers the small decisions worth explaining.

## Right now

1. Clone the repo.
2. `pnpm install`
3. `pnpm dev`
4. Open the printed localhost URL. You'll see a page confirming the foundation (event bus, database connection, theme tokens) is wired up correctly — no actual tools yet.

## What's coming, in order

See [`Putter-Build-Roadmap.md`](../../Putter-Build-Roadmap.md) for the real, current plan. Short version: Task Manager first, then Focus Timer, Habit Tracker, and Self-Care Routines, then a polish pass, then Notes and the Planning Dashboard.

## Once real tools exist

Each tool gets its own section here, written the moment it's usable — what it does, what it doesn't do (yet), and any non-obvious behavior worth knowing (e.g., how recurring tasks handle a missed day). Screenshots/GIFs once there's something worth screenshotting.
